## AI use policy

We’re starting to use LLMs/MCPs/GPTs and all kinds of other 3-letter acronyms more heavily across Metabase. This is great, and all kinds of exciting things are starting to take shape.

Before things get too out of control on the slop-train, I want to make sure that some basic expectations are clear about how we use them.

*You are ultimately responsible for the posts, documents, numbers and code you deliver.*
Whether by yesterday’s, today’s or tomorrow’s tools, if you deliver it or create it, you are responsible for it being accurate, useful and serving whatever goal it is you are trying to accomplish.

If you ever catch yourself saying something like “Claude/ChatGPT/MyMom says <blank>”, please pause. Read what you found through the tool, make sure it makes sense to you and then pass it on as something that you learned through the tool. If you don’t understand what you’re repeating or know if it's actually accurate, you’re acting as a force of chaos in the conversation.

*You’re expected to read every word of something you generate and make sure it makes sense.*
Don’t create AI Slop that other people need to somehow verify. There are no points for creating a 50 page report on the price of weasel pelts in outer Mongolia that you haven’t even read, let alone verified. If you submit a PR, you should be the first (and most brutal) reviewer of what your coding agents produce. If you aren't able to review it, then you’re just creating a problem that someone else has to deal with now.

*Respect the Signal to Noise Ratio, edit aggressively:*
It’s now trivial to create an infinite amount of writing, that you then throw to other people to deal with. Please be mindful of other people’s time and always make sure you’re adding relevant information. Err on the side of terseness, and don’t let the token-burning prose styles of LLMs add more noise to what you’re producing. Expect to clean up the output of whatever process is being created. Try to avoid "AI-Slop voice" in the writing, either by editing or prudent skills/prompting.

*Recurring reports need recurring attention*
If you’re creating recurring reports that go to others, you must read each one and continually tweak it so that it stays relevant. If you can’t either ask someone else to manage it, or kill it. AI Slop doesn’t get more valuable if you cron it.

*Be Honest with yourselves and others as to whether something is an experiment*
We’ll be playing with lots of exciting approaches and hopefully generating a lot of NotReadyForPrimetimeExperiments. That’s great, have at it. But please be clear about when something is ready for others to rely on.
